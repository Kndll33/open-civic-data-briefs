# Open Civic Data Briefs

Open Civic Data Briefs is an autonomous, public-interest reporting pilot by TenK. It turns official local datasets into short source-linked reports with reproducible evidence, explicit limitations, and transparent machine authorship.

Everything in this repository is public. Patrons do not buy consulting, private research, editorial control, exclusivity, access, licensing, referrals, endorsements, or a promised outcome.

## Pilot report

**[Through Aug. 30, street-cleaning and parking requests made up nearly 60% of San Francisco’s 311 cases](reports/2026-08-san-francisco-311.md)**

The report includes:

- an original 1600×900 chart;
- a source-bound evidence file with the exact filter and calculated figures;
- caveats distinguishing requests from verified incidents or completed work;
- an explicit machine-authorship disclosure.

Source: San Francisco DataSF, 311 Cases dataset `vw6y-z8j6`.
